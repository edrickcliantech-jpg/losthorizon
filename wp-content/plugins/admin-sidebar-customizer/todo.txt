Admin Sidebar Customizer - Changelog (All completed)
====================================================

1. [DONE] Fix horizontal drag on #adminmenu
   - WordPress core sets #adminmenu to width: 160px, overflowing the 72px wrapper
   - Added explicit width: 72px on #adminmenu, width: 240px when expanded
   - Added overflow-y: visible to prevent clipping submenus

2. [DONE] Fix submenu disappearing when expanded
   - overflow-y: auto on #adminmenu created a scroll container that clipped submenus
   - Submenus use position: absolute; left: 100% so they extend outside #adminmenu
   - Kept overflow-y: visible on #adminmenu in all states

3. [DONE] Fix admin bar icon/text alignment
   - Changed .ab-item from line-height centering to display: flex; align-items: center
   - Added gap: 6px between icon and text
   - Added flex centering on .ab-icon and .ab-label children

4. [DONE] Fix content area gaps (margin top/left)
   - Core CSS sets #wpcontent margin-left: 160px and padding-left: 20px
   - Added overrides for body.folded #wpcontent and body.auto-fold #wpcontent
   - Reset #wpwrap margin/padding to 0
   - Set body background to --asc-page-bg to eliminate visible gaps

5. [DONE] Wrap content area in glass panel card
   - Applied to #wpbody: background, backdrop-filter: blur(16px), border-radius: 12px
   - Added box-shadow, border, overflow: hidden
   - Applied same styling to #wpfooter
   - Mobile (<=782px): removed card effects since sidebar becomes bottom bar

6. [DONE] Add 16px gap between sidebar and content
   - Desktop: margin-left 108px (92 sidebar edge + 16 gap)
   - Desktop expanded: margin-left 276px (260 + 16)
   - Tablet (<=1024px): margin-left 90px (74 + 16)
   - Tablet expanded: margin-left 306px (290 + 16)

7. [DONE] Uniform button height
   - All menu items (collapsed + expanded) set to height: 40px
   - Removed between-every-item separators, kept group separators only
   - Group separators: after Dashboard (border-bottom), Comments, Plugins

8. [DONE] Sidebar scroll when items overflow
   - #adminmenu: overflow-y: auto, overflow-x: hidden
   - Submenus switched to position: fixed (escape scroll container)
   - JS positions submenus dynamically using getBoundingClientRect()

9. [DONE] Click-based submenus (no more hover)
   - Removed all hover-based submenu behavior
   - Items with submenus get class "asc-has-submenu" via JS markHasSubmenu()
   - Clicking a.menu-top on items with submenus toggles the submenu (no navigation)
   - Clicking items without submenus navigates normally
   - Small "›" indicator on collapsed items with submenus, changes to "‹" when open
   - Submenu position: fixed, JS positions with setProperty(..., 'important')
   - Close submenus: click outside, Escape key
   - Properly handles opensub class fight from WP core JS

10. [DONE] Fix dashicons font-family
    - Added font-family: dashicons !important to sidebar and admin bar icons
    - Removed universal * font-family selector that was breaking icons

11. [DONE] Fix expanded sidebar menu names
    - Added .wp-menu-name overrides for expanded state
    - opacity: 1, visibility: visible, width: auto, flex: 1 1 auto

Margin calculations:
   - Sidebar: left 20px + width 72px = right edge 92px
   - Expanded: left 20px + width 240px = right edge 260px
   - Admin bar: top 20px + height 48px = bottom 68px
   - Sidebar top: 78px (admin bar bottom + 10px gap)
